# Task: api-stages (branch demo/api). Owns studio/server/stages.py, studio/server/manual.py, studio/server/poses.py (new files) and minimal registration edits in studio/server/app.py.

Objective: the new HTTP routes for targets, stage selection, pose jobs and manual mode. Existing routes stay unchanged.

Build
1. `GET /api/targets` and `GET /api/targets/{id}` (from `studio.data.loader` if present, else a stub fixture you create under `studio/server/fixtures/`), `GET /api/data/{path}` serving cleaned structures from `studio/data/structures` (path-traversal safe, whitelist `.pdb`/`.sdf`/`.json`).
2. Stage handling in `POST /api/runs`: `config.stage == "binding"` uses `studio.binding.stage.build_binding_engine` when importable (else 503 with a clear message); `"pharmacology"` is the existing path. Validate `target_id`, apply caps.
3. Pose jobs: `POST /api/poses` (`PoseRequest`) -> `PoseResult(status="queued")`, `GET /api/poses/{job_id}`. The executor calls a DynamicBind service via an env-configured URL (`DYNAMICBIND_URL`, default `http://127.0.0.1:8100`) with `POST /dock {target_id, smiles}` / `GET /jobs/{id}` (document this tiny contract in `studio/server/POSES.md` for the lambda-ops agent). If `studio/data/precomputed_poses/<target>/<canonical-smiles-hash>.json` exists (a serialised `PoseResult`), return it immediately with `source="precomputed"`. If the service is unreachable return `status="failed"` with a clear note, never a fake pose. In-memory job table with TTL; global concurrency 1.
4. Manual mode: `POST /api/manual/preview` (`ManualPreviewRequest` -> `ManualPreview`: apply the registry edit at the site, run sanity check if present, score with RDKitScorer (and BindingScorer extras if `target_id` given and importable), explanation via RDKitExplainer, 3D molblock + atom_map via `studio.engine.geometry`), `GET /api/manual/applicable?smiles=&locked=` (list of `{edit_id, name, category, site, rationale}` from the registry), `POST /api/manual/sessions` / `POST /api/manual/sessions/{id}/steps` (append a `ManualStep`), `GET /api/manual/sessions/{id}/export` (JSONL download, one transition per line in the policy format `(parent_smiles, edit_id, site, child_smiles, reward)` as JSON keys). Sessions in memory + append-only JSONL under `STUDIO_CACHE_DIR/manual/`.
5. Auth for the public deployment: if env `STUDIO_API_KEY` is set, every `/api/*` route except `/api/health` requires header `X-Studio-Key` equal to it (constant-time compare). Keep CORS closed (the Space proxies server-side). Keep the existing body-size / rate limits.
6. Tests for each route using fakes (no DynamicBind, no PLAPT), including path traversal, missing key, precomputed pose, unreachable service.

Acceptance: full suite green (`pytest studio tests/studio_suite`), routes listed in `studio/server/README_ROUTES.md`.
