Problem found by the integrator: a real run on the seed `CCOC(=O)c1ccc(cc1)[N+](=O)[O-]` "removed an alert" by ending at `CNOC(=O)c1ccc([N+]=O)cc1` (a hydroxylamine ester and a charged nitroso group). The score improved by breaking chemistry, and accepted edits included swaps to sulfur (adds an alert) and adding bromine. Judges will see this. Fix it so accepted children are chemically plausible and edits shown by default are sensible.

Build
1. `studio/sanity/checks.py`: `check_child(parent_smiles, child_smiles) -> (ok: bool, reason: str)`, fast (< 2 ms typical). Reject: RDKit sanitization failures; any radical electrons; net formal charge different from the parent's; charged atoms that are not part of a recognised neutral zwitterion pattern (nitro, N-oxide, sulfoxide-type, ammonium/carboxylate pairs); non-nitro `[N+]=O`; O-O, N-N-N and other implausible heteroatom chains (keep a small curated SMARTS list in `studio/sanity/patterns.yaml`, each with a comment saying why; be conservative so ordinary drug motifs such as hydroxamic acids, N-oxides, disulfides, hydrazides, sulfonamides stay allowed); fragments (multi-component SMILES); extreme ring strain (3-membered carbocycles are allowed, 3-membered rings with 2+ heteroatoms are not). Return a short machine reason such as `net_charge_changed`.
2. `studio/registry/demo_safe.yaml`: review all 83 ops and mark each `demo_safe: true/false` with a one-line reason. Be conservative: default-shown edits should be ones a medicinal chemist would recognise (bioisosteric swaps, common functional-group interconversions, polarity/halogen tuning), not arbitrary heavy-atom swaps. Expose `registry.applicable(..., demo_safe_only=True)` (default on; env `STUDIO_ALL_EDITS=1` disables). Keep the existing signature compatible.
3. Engine hook: call `check_child` before a child is accepted or emitted as `accepted`; rejected children are dropped (not emitted as accepted); count rejections per reason and put a short summary in `PolicyMetrics.note` for each generation (for example "rejected 6: net_charge_changed 4, bad_pattern 2").
4. Tests: a positive and a negative case for every rule, including the nitroso case above, nitro -> nitrile (must pass), ester -> amide (must pass), hydroxamic acid (must pass).
